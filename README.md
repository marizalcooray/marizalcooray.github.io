# Personal site

Files:
- index.html  — the page
- Cooray_CV.pdf — your CV. To update it, upload a new file with exactly this name.
- photo.jpg   — optional; add a square headshot with this name and it appears automatically

To publish on GitHub Pages:
1. On github.com create a new public repository named  <your-username>.github.io
2. Upload these files (Add file > Upload files), commit to main.
3. Wait one to two minutes. The site is live at  https://<your-username>.github.io
