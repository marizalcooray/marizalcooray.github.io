# Laos debt: dynamic factor models

Stata code and data for dynamic factor models of Laos' exchange rate and balance of payments.

- `Laos_DFM_v081024.do`: Stata do-file (October 2024)
- `dby.xlsx`: annual data, 1990–2022
- `dbq.xlsx`: quarterly monetary and external data, 2012Q3–2022Q4
- `dbbop.xlsx`: quarterly balance of payments data, 2012Q1–2024Q1
